# André OS · Home/Shell visual v3

## Objetivo

Refinar a Home global após validação em produção, com foco em hierarquia visual, menos peso e contexto correto.

## Decisões

- a Home global mostra foco e atalhos, não uma réplica da operação Planet;
- o foco principal continua dominante, mas deixa de ocupar quase toda a largura e altura sozinho;
- os pontos complementares ficam compactos numa coluna lateral;
- a sidebar mostra somente ambientes reais;
- a identidade global passa a usar `André OS · Operating System` no desktop;
- o contexto Planet aparece somente ao entrar no ambiente Planet;
- mobile permanece intocado.

## Cache

Os assets visuais e de comportamento da Home/Shell recebem versão `20260807-1` para impedir reaproveitamento da versão anterior pelo navegador após deploy em produção.
